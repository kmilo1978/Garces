# Casa Campestre La Isabela - Guía de Proyecto

Sitio web oficial de Casa Campestre La Isabela, en Las Lomitas, La Ceja (Oriente Antioqueño).

## Arquitectura y Tecnologías
- **Framework:** React con TanStack Router / TanStack Start
- **Estilos:** Tailwind CSS con paleta campestre (#FAF8F5, #18281E, #2D6A4F)
- **Iconos:** Lucide React
- **Idioma:** Soporte bilingüe interactivo (Español / Inglés)
- **Arrendamiento:** 2 habitaciones, 3 camas, lote de 1.500 m², contrato formal con inmobiliaria (mínimo 6 meses)
- **Contacto:** Integración directa con WhatsApp para atención y agendamiento de visitas
